## Tabs 样式 Token 化改造 + 样式约束文档
- 按用户要求：公共 Tabs 样式改为「Theme Token 为主 + antd-style 兜底」，不用全局 CSS/less。
- 关键发现：antd-style createStyles 回调的 token 是「全局 AliasToken」，**不含组件专属 Token**（如 Tabs 的 itemColor/titleFontSize），所以组件专属外观必须配置在 `tokens.ts` 的 `components.Tabs`，createStyles 里重复写会覆盖 Token 导致主题失效。
- AppTabs.tsx 重构：createStyles 移除 itemColor/titleFontSize/horizontalItemPadding/inkBarColor 等冲突属性，只留 Token 表达不了的 3 件事：①隐藏 600 字重占位撑宽（选中加粗不抖动）②数字徽标 em ③ink-bar 圆角/高度。tokens.ts 的 Tabs 补 `colorBorderSecondary: #2a2731`（nav 底部边框对齐资产页 --sg-border）。
- 约束文档：docs/apps/web.md 新增 3.3.1「组件外观：Theme Token 优先，antd-style 只补 Token 表达不了的」，并强化 3.3 禁止新增业务 .css/.less，全局样式用 antd-style、组件用 createStyles/createGlobalStyle、由 ThemeProvider 挂载。
- 验证：tsc -b、vite build、biome lint 全通过；dev server HMR 正常；通过 dev 抓模块确认 Token 链路生效（AppTabs 无冲突属性、tokens.ts 含目标值）。
- 后续约定：web 新样式一律优先 antd-style + Theme Token，不写全局 CSS/less；历史 styles/*.ts 全局样式属遗留，新代码不得新增。
